🚀 DEPLOYMENT STEPS:

STEP 1: Set Up MongoDB Atlas (FREE)
   1. Go to https://www.mongodb.com/cloud/atlas
   2. Create FREE account (no credit card)
   3. Create FREE cluster (M0 - 512MB)
   4. Create database user
   5. Get connection string
   6. Whitelist all IPs: 0.0.0.0/0

STEP 2: Configure Secrets Locally (for testing)
   1. Copy .streamlit/secrets.toml.example to .streamlit/secrets.toml
   2. Add your MongoDB URI
   3. Add API keys (Groq, Anthropic, etc.)

STEP 3: Test Locally
   ```bash
   pip install streamlit pymongo bcrypt
   streamlit run streamlit_app.py
   ```
   Open browser to http://localhost:8501

STEP 4: Deploy to Streamlit Cloud (FREE!)
   1. Go to https://streamlit.io/cloud
   2. Sign in with GitHub
   3. Click "New app"
   4. Select:
      - Repo: venkatashivabramha/Gen-AI
      - Branch: main
      - File: streamlit_app.py
   5. Add secrets in Advanced settings:
      ```toml
      MONGODB_URI = "mongodb+srv://..."
      GROQ_API_KEY = "gsk_..."
      ```
   6. Click "Deploy"
   7. Your app will be live at:
      https://your-app-name.streamlit.app
